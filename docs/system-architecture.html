企業智慧化

CharPhone 訂單管理系統 ＋ AI Gateway 整體架構

傳統 ERP → 企業落地 AI · 從「查資料」到「問資料」

一份文稿整理 web / API / AI / 知識庫 的完整藍圖

這是一套什麼系統？

一套服務翻砂金屬鑄造工廠的企業系統，由訂單管理 ERP（CharPhone） 與企業 AI Gateway 組成：

  • ERP 內部作業：訂單 → 生產工單 → 入庫 → 出貨 → 應收帳款 / 收款 → 結案
  • AI 加值：讓老闆用自然語言問「這個月營收」「哪些訂單會延遲」「庫存夠不夠」，AI 自動查 ERP 並彙整回答
  • RAG 知識庫：把公司文件（報價流程、SOP）餵進去，AI 依文件回答

核心價值：把「資料」變成「能被問的知識」

CharPhone — 傳統 MVC Web

呈現場（View）

  • 42 支 JSP · JSP/JSTL 自訂標籤 + 原生 JS fetch
  • 模組：訂單 / 生產 / 出貨 / 應收 / 客戶 / 品項 / 庫存 / 模擬 / 儀表板 / 帳號

控制層（Servlet 18 支）

  • LoginServlet、OrderServlet、ProductionServlet、DeliveryServlet、InvoiceServlet…
  • 業務規則 + JDBC 交易都寫在這裡

資料存取（DAO 16 支）

  • OrderDao / InvoiceDao / InventoryDao…（全 PreparedStatement）
  • HikariCP 連線池 · BaseDao 讀 DB_URL/DB_USER/DB_PASS

安全

  • AuthFilter 全站 session 驗證 · 密碼 SHA-256 + salt

規模：42 JSP · 18 Servlet · 16 DAO · 11 Model · 11 張表。無獨立 service 層，控制邏輯在 Servlet。

Agent 工具與模型路由

10 支工具（ToolRegistry 自動註冊）

  • query_orders · query_customers · query_deliveries
  • query_inventory · query_production
  • query_sales_summary · query_receivables
  • query_risk_orders · query_dashboard_kpis
  • query_knowledge（RAG 知識庫）

ModelRouter

  • 主供應商：OpenRouter（nemotron-3-super-120b:free）
  • 備援：Gemini（自動 Failover）
  • Circuit Breaker：連續失敗 3 次 → 暫停 60s → 自動恢復
  • 每支工具執行逾時 20s、結果上限 32KB

安全 · 控管 · 稽核

認證與授權

  • API Key（DB 只存 SHA-256 雜湊）
  • 角色：ADMIN（全部工具）/ USER（客戶、知識庫）

限流

  • Per-Key：滑動視窗 per-min + daily 配額（可選用）
  • Nginx：30 req/min/IP + burst 10

資料保護

  • 稽核落 DB（audit_log / tool_audit_log）
  • 敏感資料自動遮罩：身分證、銀行帳號、電話

網路防護

  • Coraza WAF + OWASP CRS
  • IP 白名單 · 登入限流 · TLS

Admin 後台 (admin.html) 提供 Key 管理、稽核查詢、用量報表、RAG 文件管理。

一個實際問題怎麼被回答

老闆問：「這個月營收多少？哪幾個客戶佔比最大？」

sequenceDiagram
  participant U as 老闆
  participant G as AI Gateway
  participant M as ModelRouter
  participant T as 工具 query_sales_summary
  participant D as mydb
  U->>G: POST /agent/run（自然語言）
  G->>M: 呼叫 LLM + 工具宣告
  M->>T: 剖析出「呼叫 query_sales_summary"
  T->>D: SQL 彙總營收/客戶排行
  D-->>T: 資料 JSON
  T-->>M: 工具結果
  M-->>G: LLM 彙整成一段話
  G-->>U: 「本月營收 X 元，前五客戶為…」

全程：身份驗證 → 工具權限檢查 → 資料遮罩 → 稽核落 audit_log / tool_audit_log。

總結

  • 成熟 ERP：CharPhone 已覆蓋完整工廠作業流程（訂單→生產→出貨→應收→結案）
  • 企業落地 AI：AI Gateway 以「工具呼叫」安全讀取 ERP，不改動原系統程式
  • 知識庫 RAG：公司文件可被自然語言查詢，符合知識管理
  • 可受管控：API Key、限流、稽核、遮罩、WAF、白名單，層層防護
  • 可擴充：新增一支工具 = 新開一個 ToolHandler；模型可熱切換

「資料」都在，現在它「會被問了」。
